Build a polished, modern stealth company website for NeuBlox AI Inc. at neublox.ai.

Context:
NeuBlox is a stealth Physical AI company. The website should create credibility and curiosity without revealing the company’s detailed product, architecture, team, customer pipeline, technical roadmap, patents, silicon strategy, or exact robotics use cases.

Primary website goal:
Create a professional landing site that says NeuBlox is working on next-generation infrastructure for Physical AI and lets investors, partners, talent, and ecosystem collaborators stay in touch.

Technology requirements:

* Use Next.js with TypeScript.
* Use Tailwind CSS for styling.
* Create a clean, responsive design for desktop and mobile.
* Use a Markdown or MDX-based blog system so blog posts can be added easily.
* Keep the site fast, minimal, SEO-friendly, and production-ready.
* Include simple Open Graph metadata.
* Include a sitemap and robots.txt if practical.
* Do not use a database unless necessary.
* Contact form can initially use a mailto fallback or a configurable endpoint placeholder.
* Put all configurable company/contact values in a simple config file.

Brand direction:

* Company name: NeuBlox
* Use the following colors:

  * Primary blue: #2e5e7f
  * Dark navy: #183f59
  * Medium blue: #4b789e
  * Light blue: #6fa3c8
  * Background: white or very light blue-gray
* Design style: premium, restrained, deep-tech, Physical AI, robotics infrastructure, venture-backed stealth startup.
* Avoid flashy AI clichés, cartoon robots, humanoid imagery, or generic chip graphics.
* Use abstract geometric visuals, subtle grid patterns, motion-inspired lines, or block-inspired motifs.
* Include a placeholder logo image path: /public/neublox-logo.png. If the logo file is missing, render the text “NeuBlox” in a polished wordmark style.
